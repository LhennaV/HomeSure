📱 Mobile Table Layout Demo

Resize your browser to see tables convert to cards on mobile!

💡 How it works

Desktop (> 768px): Shows as normal table
Mobile (< 768px): Automatically converts to card layout
Requirement: All <td> elements must have data-label="..." attribute
