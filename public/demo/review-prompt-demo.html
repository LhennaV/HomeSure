📱 Auto Review Prompt

Phone app-style review popups that appear automatically

💰
After Payment
Show prompt after user completes a payment
🏠
After Rental
Prompt appears after a rental period
🎲
Random Prompt
Appears randomly while using the app

How It Works

  • Auto-appears after key actions (payment, rental completion)
  • Star rating - Users tap 1-5 stars
  • Optional feedback - Text appears after rating
  • "Maybe Later" - Dismisses for 7 days
  • Smart timing - Won't show if recently prompted
  • localStorage tracking - Prevents spam
  • Thank you screen - Confirms submission
// Add to any page
<script src="components/review-prompt.js"></script>

// Trigger after payment confirmation
ReviewPrompt.trigger({
  context: 'payment',
  propertyName: '1-Bedroom Apartment',
  delay: 2000 // 2 seconds after payment
});

// Random trigger (use in app load)
if (Math.random() < 0.3) { // 30% chance
  ReviewPrompt.trigger({ context: 'random' });
}
